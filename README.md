# Турнир «Кубок Лаборатории»

Олимпиада на префиксные суммы для Младшей лаборатории. Открыть: https://vaxavan.github.io/kubok-laboratorii/

Внизу страницы — справочник «Python под рукой»: арифметика, срезы, все методы строк, списков, кортежей,
словарей и множеств, Counter, deque, heapq, встроенные функции и сравнение коллекций. Каждый пример можно
изменить и запустить (настоящий Python — Pyodide в отдельном потоке), в конце разделов — задачи «Проверь
себя» с автопроверкой. Прогресс турнира хранится в браузере под ключом `cup-lab`, справочника — `cup-lab-ref`.

## Тренажёр: строки, списки, множества, словари

Внизу страницы, ссылка — https://vaxavan.github.io/kubok-laboratorii/#trenazher. Теория с живыми примерами и 19 задач с автопроверкой: уровень 1 (разминка), уровень 2 — серии похожих задач (копилка по ключу ×4, сколько разных ×4, подсчёт ×3), уровень 3 (сложные, одна — на скорость). Прогресс хранится в браузере под ключом `cup-lab-tr`.

В тренажёре слева — меню всех блоков и задач с отметками решённых. Блок «Модуль 3 · задания курса»: 3.1 lambda и key, 3.2 рекурсия (без циклов — проверка это ловит), 3.3 словари и множества, 3.4 контрольная, 3.6–3.7 исключения и файлы (файлы для тестов проверка создаёт сама), контрольная модуля 3 — 63 задачи, условия пересказаны своими словами.
